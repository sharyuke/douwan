# 2026-11-06 中午 电脑端图纸调整挪到命令栏钉板旁边

用户要求电脑和平板端口，把图纸调整放到钉板选择旁边，点击是下拉，样式不变。

## 改法

- `EditorView.vue`：图纸转换命令栏在钉板右侧加「图纸调整」按钮，点开 `.csAdjustPop` 下拉，面板仍是 `ImageAdjustPanel`（成品尺寸 + 智能抠图）。右侧栏不再有这一行。
- 下拉与钉板 / 色板互斥，Esc 和点外面可关。自由画布没有这颗按钮。
- 验收脚本改去命令栏入口：`verify-console` / `verify-matte` / `verify-size-guard` / `verify-art-scale` / `audit-photo`。
- `EditorGuide.vue` / `SizeQuickCard.vue` 文案跟着改。
