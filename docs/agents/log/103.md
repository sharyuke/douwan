# 2026-11-07 傍晚 换图前提示保存当前作品

画布上已经有作品时，更换图片会先弹出「保存当前作品」。空画布不弹，直接换图。

## 口径

- **取消**：不保存，直接换上新图片。关闭按钮、Esc、点遮罩等于取消这次更换，不保存也不换图。
- **保存**：先把当前画面存进「我的作品」，再换上新图片。新图仍是一张未保存的新画布，地址收回 `/editor`。
- 未登录时点「保存」先走登录框。登录成功后保存并换图；关掉登录框则中止换图，当前作品留在画布上。
- 桌面「更换图片」、手机「换图」、拖图、左栏上传、素材库选素材走同一道提示。文件选择框仍是点按钮就打开，提示出现在选好文件、真正替换之前。

## 验证

- `AUDIT_WIDTHS=desktop,mobile node scripts/audit.cjs --eval-file scripts/audit-new-save.js /editor`：6 个页面全过。空画布不弹；已有作品必弹；点取消后旧作品逐字节不变；点保存后旧作品落盘、新图不写入旧作品、作品数不变。
- 另一次探针确认弹窗标题「保存当前作品」、两个按钮是「取消」「保存」，桌面 512×202、手机 353×196，都在视口内。
