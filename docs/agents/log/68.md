# 2026-11-05 深夜 放出手机验证码登录入口

用户要求：「把手机登录的功能放出来」。后端短信接口 2026-10-31 已上线，凭据也已在 qq 配齐
（线上 `/api/v1/auth/sms/status` 返回 `configured:true`），缺的是前端入口——上一版按设计稿撤下了
手机号页签，只留微信 + 邮箱。

## 改法

- `src/components/ui/LoginDialog.vue`：弹窗打开时查 `/auth/sms/status`，`configured` 为真才显示
  「手机号登录 / 邮箱登录」页签并默认落在手机号；未配置或查询失败时保持原「或使用邮箱」版式。
- 手机号表单：手机号 + 验证码、60 秒重发倒计时、错误提示；未注册手机号由服务端自动建号。
  登录成功走 `loginWithSmsCode()`，与邮箱 / 微信一样写令牌并关闭弹窗。
- 隐私说明只在入口显示时补一句「验证码只用于校验本人手机号」；组件卸载时清掉倒计时定时器。
- 自检：`scripts/verify-sms-login.cjs` 去掉 `SMS_LOGIN_RELEASED` 开关，默认跑完整流程，
  并支持 `VERIFY_VIEWPORT=390x844` 跑手机档、增加弹窗横向溢出断言；
  `verify-console.cjs` 不再断言「没有手机号页签」；`audit-login-public.js` 把页签与「或使用邮箱」
  都算作合法入口。

## 验证

- `pnpm build` 通过。
- `pnpm verify:sms-login`（桌面 1440×900）：页签出现、默认手机号、非法手机号报错、发码倒计时、
  错误验证码提示、正确验证码登录成功（令牌落库、资料带手机号）、切邮箱页签正常，console 报错 0。
- `VERIFY_VIEWPORT=390x844 pnpm verify:sms-login`：同样全过，弹窗无横向溢出。
- 线上只读复验（真 Chrome，桌面 + 手机 390×844）：登录弹窗出现两个页签、默认手机号表单、
  邮箱表单隐藏、「或使用邮箱」分隔线消失、无横向溢出、console 报错 0。
