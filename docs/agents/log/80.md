# 2026-11-06 中午 工作台顶栏保存后显示绿色「已保存」

用户要求保存后顶栏左上角状态从灰色「未保存」变成绿色「已保存」，颜色和成功按钮一致。

## 改法

- `pindoudou/src/views/EditorView.vue`：`.csSaved.on` 文字用 `--green-deep`，圆点用 `--green`（与 `.btn.green` 同一套令牌）。未保存仍是辅助灰。

保存后文案本来就会切到「已保存」；这次补的是已保存时的文字颜色。

## 验证

- 本地无头 Chrome：未保存灰字灰点，保存后文案「已保存」、文字 `rgb(44, 122, 70)`、圆点 `rgb(127, 211, 154)`，9/9。
- 产物 CSS 含 `.csSaved.on{color:var(--green-deep)}` 与圆点 `background:var(--green)`。
