# 2026-11-08 下午 打开首页不再闪现纯文字页

打开首页时，会先闪出一整页纯文字（「豆玩拼豆图纸生成器」加几段说明），再换成带插画的主视觉。这段文字是后端注入到 `<div id="app">` 里的 SEO 正文（`.seo-shell`），给爬虫读的，浏览器在 Vue 挂载前也会把它画出来。

修法：`pindoudou/index.html` 的 `<head>` 里加一条 `#app > .seo-shell{display:none}`。正文仍在原始 HTML 里，爬虫照常读到 H1、长文和 JSON-LD，只是用户在挂载前看不到它。挂载后 Vue 会整段替换掉 `#app` 的内容，所以这条样式不影响页面本身。

## 验证

- 线上首页源码：隐藏样式在 `<head>`，`<div class="seo-shell">`、H1「豆玩拼豆图纸生成器」和三段 `ld+json` 都还在。
- 无头浏览器拦截脚本、停在 Vue 挂载前那一帧：`.seo-shell` 的 `display` 是 `none`，页面可见文字长度为 0。
- 挂载后三端（1440×900 / 834×1112 / 390×844）：`.homeV3` 主视觉与插画在，标题「把灵感，拼成喜欢的样子」，页脚紧跟主视觉（footTop = heroBottom = 523），无横向溢出，控制台无报错。点「立即创作」进 `/editor`，编辑器里没有 `.seo-shell` 残留。
- `scripts/verify-seo-v3.cjs --url https://dw.sharyuke.com`：62 项里 55 项通过。失败的 7 项都在断言旧版首页的 `.homeHero`，首页 2026-11 已改成 `.homeV3`，脚本没跟上，与这次改动无关；原始 HTML 的 SEO 断言（标题、描述、H1、长文正文）全部通过。
