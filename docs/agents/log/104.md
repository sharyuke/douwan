# 2026-11-07 傍晚 撤销覆盖操作台尺寸、色板和参数

操作台左侧的撤销，以及 Ctrl+Z，现在记的是整次操作，不只是画笔、橡皮、填充、换色、套索这些格子改动。

## 口径

- 记一步：换品牌色板、切换生成方案、改颜色数、适应方式、抖动、清理、增强、抠图、卡通化及因此触发的重新生成、改成品尺寸、换底板、裁切原图、恢复方案。
- 换图、选素材、打开存档、重置工作台仍然另起一份图纸，撤销栈清空。
- 缩放、选工具、看图方式、作品名不进撤销。
- 换色板或改尺寸之后，再撤销会回到改之前的图纸，包括那之前手画的豆子。

## 验证

- 桌面探针 `scripts/audit-undo-ops.js`：在夹具图中心画一笔后，换色板、换方案、颜色数 14 改 8、尺寸 52 改 40，撤销和重做都能回到原品牌、原尺寸、原颜色数，中心那一笔还在。
- 公网包内含「撤销上一步操作，含尺寸、色板和参数」和「画一笔，或改一下尺寸、色板、参数」。
