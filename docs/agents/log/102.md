# 2026-11-07 傍晚 换色右侧加菜单与视频教程

换色工具右侧新增箭头，点开是三项菜单：自动替换相近色、替换为空豆、查看教程。
前两项改变「点一格」的行为，第三项打开一个带字幕和背景音乐的小弹窗。

## 交互口径

- 箭头与画笔 / 橡皮的尺寸箭头同一套外观（`.csTool__sizeBtn`），但 `data-swap-arrow`，
  菜单卡片 `#cs-swap-menu` 用 `position:fixed` 贴在工具轨右缘外侧，避开轨道 `overflow`。
- 菜单项：`自动替换相近色`、`替换为空豆`、`查看教程`。点前两项选中换色工具并切模式，
  再点同一项回到默认；点换色按钮本身也回到默认（换成当前画笔色）。
- `swapMode` 三档：`brush`（默认，换成画笔色）/ `nearest`（同系列 ΔE00 最小）/ `empty`（EMPTY）。
- 三种模式都按色号 id 整图替换，各是一步撤销。工具栏的悬停说明跟着模式变。
- 点外面、Esc、打开尺寸卡、收起工具轨都会关掉菜单。

## 换色取色的修正

换色原来用画布组件的 `brush` 计算属性，它只在图纸色板里找画笔色，找不到就退回
「最后一颗豆」。当前画笔色还没进图纸色板时，换色会换成画布上已有的颜色，和工具轨上
显示的颜色对不上。现在换色分支按 `brushColorId` 从品牌色板取色，和 `paintAt` 同一条路。

## 替换为空豆的边界

`recalcStats` 修剪死色时只处理「还剩至少一色」的情况。把画布上最后一种颜色换成空豆
（或橡皮擦到一颗不剩）会留下死色。补了 `palette.length === 0` 分支：格子全 `EMPTY`，
色板清空。

## 教程视频

- 入口：菜单「查看教程」→ `BaseDialog size="sm"`，标题「换色教程」，视频 `tutorials/swap.mp4`。
- 产物：`public/tutorials/swap.mp4`（960×540，约 20.5 秒，H.264 + AAC，1.2 MB）和
  `swap-poster.png`。
- 做法：`scripts/make-swap-tutorial.cjs` 用无头 Chrome 打开构建好的 `/editor`，摆一张
  三色小图，按真实按钮走一遍换色并截图；`scripts/swap-tutorial-recorder.html` 把截图串成
  镜头，用 Canvas 画文字解说、WebAudio 合成背景音乐，`MediaRecorder` 直接录成 MP4。
  解说条在画面上方，不会被播放器底部控制条盖住。
- 重新生成：`pnpm build` → `node scripts/make-swap-tutorial.cjs`。ffmpeg 只用来把 moov
  移到文件头；找不到时视频仍能播。脚本会自动找 `pindoudou/.tmp/ffbin` 里的 ffmpeg-static。
