# 2026-11-06 下午 保存后的作品放大时自动加颜色、按原图重算

用户要求：保存后的作品继续放大尺寸时，要自动增加颜色数量来增加细节，不要把原图直接放大。

## 改法

- `setCanvasSize`：放大到比见过的每一份都大时，不再还原尺寸缓存，也不再把旧格子按块铺开。有真原图就按新网格重新取样，并把目标色数抬到 `colorFloorForCells` 这一档（只往上抬）。缩小、以及回到用过的尺寸，仍逐格还原。
- 打开存档后内存里的源图是落过色的。放大超过保存时的网格时，改用没落色的 512 px 快照做面积取样，新格子才能分出过渡色。源图还在解码时先等，避免退回按块铺开。
- 色数抬高后丢掉旧尺寸缓存，避免缩回去时还原成加色之前的那一版。
- 尺寸说明行会写「颜色数提到 N」。

## 验证

无头探针（52 格、12 色保存后再打开，放大到 104）：按原图重算，目标色数 12 → 48，实际用色 6 → 20，2×2 同色块占比 0.815。缩回再放大逐格 diff 0。未保存的 104 → 52 → 104 逐格还原，颜色数不丢。
