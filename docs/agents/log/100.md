# 2026-11-07 下午 套索局部移动保留没选中的豆子

套索圈住一部分再拖动时，没选中的豆子会被扫过的选区擦掉。这一版改成每次都从按下前的画面重算。

## 改法

- 拖动中的每一步都用按下时的格子和总位移算出新位置，不再在上一格的结果上接着挪。
- 选区掩码也固定在按下时的那一份。拖回起点时，画面和选区一起回到按下前。
- 选区最后停在某一颗没选中的豆子上时，这一颗仍由选中的豆子盖住。再拖开，它会回来。

## 验证

- `node scripts/verify/lasso-move.mjs`：扫过旁边的豆子会回来，整张移动不丢豆，没选中的画布外豆子留在原地。
- `node scripts/verify/lasso-drag.cjs`：无头浏览器在工作台手绘套索，只圈住一颗，拖过旁边两颗。格子和画面上都还在；拖回起点四颗回来；撤销回到原位；整张拖动一格也不丢豆。
