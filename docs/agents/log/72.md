# 2026-11-06 首页主标减细，手机首页去掉底部导航

用户要求首页主标减细两个层级，并去掉底部导航。

## 改法

- `HomeView.vue`：主标「把灵感，拼成喜欢的样子」字重从 700 调到 400。Noto Sans SC 只有 700 / 500 / 400，减两级就是 400。字号仍是电脑 28px、手机 24px。
- `App.vue`：首页不再渲染 `MobileTabbar`。内页（帮助、素材等）的「创作 / 材料 / 素材 / 作品」底栏保留。站点页脚（备案与版权）保留。
- 首页手机端不再为底栏预留 96px 底边距。

## 验证

- 本地 `pnpm build`（含 `build-seo-pages.mjs`）通过。
- 无头 Chrome：桌面 1440 与手机 390 首页主标字重都是 400，首页没有 `.tabbar`。手机 `/help` 底栏仍是四项。
