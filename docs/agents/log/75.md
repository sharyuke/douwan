# 2026-11-06 凌晨 电脑端移动工具标上中键拖动快捷指引

用户要求电脑端「移动」工具的快捷键是鼠标中键按住拖动，并把快捷指引补上。

## 改法

- `src/data/icons.js`：「移动」补 `shortcut: '中键'`，说明改成按住鼠标中键拖动平移视野。
- `HelpView.vue`：快捷键表「按住空白拖动」改成「鼠标中键拖动」。
- `EditorCanvas.vue` / `EditorGuide.vue`：画布提示与工作台指引改成「滚轮缩放 · 按住鼠标中键拖动平移」。
- `scripts/verify-shortcuts.cjs`：悬停「移动」断言标出「中键」；本机 Chrome 路径补上 macOS。

## 验证

- 本地 `verify-shortcuts` 53/53。悬停「移动」浮出「中键 / 按住鼠标中键拖动平移视野，不修改图纸」。
- 帮助页快捷键表有「鼠标中键拖动」，没有「按住空白拖动」。
