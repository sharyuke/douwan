# 2026-11-07 傍晚 画笔菜单增加直线，手机可用画笔和换色菜单

画笔箭头里多了一项「直线」。选中之后，从按下的格子拉到指针，画的是直线。快捷键仍是 B，按住 Shift 拖左键也还能画直线。

手机底栏的画笔和换色右上角各有一颗箭头，菜单向上展开。底栏五个字还是画笔、橡皮、换色、颜色、更多工具。

## 口径

- 画笔菜单：直线、画笔大小（1–5 颗）。再点一次「直线」回到涂抹。橡皮菜单仍只有大小。
- 换色菜单：自动替换相近色、替换为空豆、查看教程。教程还是原来那支带字幕和背景音乐的视频。
- 手机上点菜单外面会先收起菜单，这一下不会画进图纸。

## 验证

- `scripts/audit-brush-line.js` 在桌面和手机都过：选中直线后拐弯拖动只留下起终点之间的直线，涂抹会经过拐角；Shift 拖动仍是直线；撤销整笔是一步。手机菜单在屏幕内，换色三项和教程弹窗都在。
- `scripts/audit-mobile.js` 手机空画布和有图纸都过，底栏五个字和同一行没变。
