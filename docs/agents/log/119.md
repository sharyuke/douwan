# 2026-11-08 下午 大钉板缩到小钉板时边缘颜色不再散开

大钉板换成小钉板时，轮廓上的颜色会散到留白里：头发边上飞出一串浅棕色碎豆，小色块裂成几块，周围还带一圈发白的边。

原因是缩小重新取样时，一格同时盖住主体和留白，面积平均混出原图没有的浅色。现在这一格里若有一种颜色占到三成以上，就落成那种颜色。没有一种颜色够集中的渐变仍按面积平均。没有原图、只能按底稿缩小的老存档，一种颜色要盖住那一块的至少一半才保留，盖不满的零星豆留空。

小钉板换大钉板时成品尺寸填到最大值的行为没有改。换回用过的大尺寸仍走缓存，逐格还原。
