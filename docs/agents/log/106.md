# 2026-11-07 傍晚 工具指引两秒后渐隐，并避开下拉菜单

鼠标停在工具上时，旁边的工具指引不再一直挂着。大约 2.5 秒后渐隐。鼠标还停在同一颗按钮上，它不会再弹出来；移开再回来，或换到另一颗按钮，才会重新显示。

画笔、橡皮、换色的下拉菜单贴在工具轨右边。这三颗工具的指引改到菜单右侧，不再盖住菜单。

## 验证

- 桌面探针 `scripts/audit-shortcut-tip.js`：画笔指引出现在菜单预留宽度之外；打开画笔菜单后两者不重叠；约 3 秒后指引消失，同一颗按钮上不再出现；鼠标离开后立刻收起，再移回来会重新显示。
