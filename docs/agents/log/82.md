# 2026-11-06 中午 取消自由画布，打开工作台即图纸转换

用户要求去掉自由画布和顶上的模式选择，打开页面直接是图纸转换。

## 改法

- `EditorView.vue`：去掉顶栏「自由画布 / 图纸转换」分段开关，命令栏固定为更换图片、素材库、卡通、钉板、图纸调整、色板。
- `EditorCanvas.vue`：空白画布只留上传卡，不再显示「从零开始，手动绘制拼豆图纸。」
- `useStudio.js`：进入工作台和打开存档都按图纸转换处理。标成自由画布的旧作品再打开也走图纸转换。
- `AccountView.vue`：个人中心去掉「自由画布 / 图纸转换」筛选，作品标签统一为图纸转换。
- 同一份 `EditorView.vue` 里已经有的钉板「自定义尺寸」一并进了这次提交，没有单独拆开。

## 验证
