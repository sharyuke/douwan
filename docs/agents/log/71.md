# 2026-11-06 凌晨 手机端导入图片去掉「已生成图纸」卡和「示例图片」

用户要求手机端导入图片后，去掉画布上方的「已生成图纸」卡片（含调整尺寸、详情），以及作品名旁边的「示例图片」。

## 改法

- `EditorCanvas.vue` 删掉 `genNotice` 整张卡和对应样式，不再发出 `resize`。
- `EditorView.vue` 去掉手机作品名旁的「示例图片」，作品名保留。
- `useStudio.js` 删掉 `fitNotice` / `publishFitNotice`。手机端导入成功不再弹推荐 toast，尺寸仍写在画布下方状态行。桌面端推荐 toast 不变。
- `scripts/audit-photo.js`、`capture-tutorial-shots.cjs` 去掉对已删除卡片的断言与清理。
