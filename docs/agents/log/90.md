# 2026-11-06 下午 刷新编辑页保留当下画布，不退回上传页

用户要求：编辑过程中刷新网页，画布要留在当下的图案上，不能清零，也不能回到上传图片的页面。未保存和已保存都一样。

## 改法

- 生成、改格子、换尺寸、换底板、保存之后，把当前图纸按存档格式写入 `sessionStorage` 的 `douzao-edit-draft-v1`。连着改时 400 毫秒合并成一次；刷新或关页时当场写完，进行中的一笔也算。
- 草稿不进「我的作品」，也不跟着同步到账号。关标签就没了。
- 打开 `/editor` 时，未保存的新图，以及还挂在当前作品上的已保存图纸，都铺回画布。已保存的作品会把地址补成 `/editor/<id>`。刚保存、还没再改的，刷新后状态仍是「已保存」；保存后又改过的，状态是「未保存」，格子是改过的那一版。
- 打开 `/editor/<作品 id>` 时，草稿属于这一件就铺草稿（比存档新的修改），否则打开存档。另一件作品的草稿不会盖上来。打开存档时，如果会话里已经有这一件的草稿，不用存档把它盖掉。
- 换一张新图、清空工作区、丢掉空白草稿时删掉旧草稿。

## 验证

无头浏览器走真实页面（`http://127.0.0.1:4393/editor`）：

- 未保存：生成后画一笔再刷新，格子与豆数还在，上传引导不出现，地址仍是 `/editor`，作品列表是 0 件，状态是「未保存」。
- 已保存且没再改：刷新后格子还在，地址补成 `/editor/<id>`，作品列表仍是 1 件，状态是「已保存」。
- 已保存后又改一格：刷新后这一格是改过的颜色（空格 -1 变成色号 2），作品 id 还在，状态是「未保存」，作品列表没有多出一件。
- 清掉草稿再刷新，画布回到上传引导。打开另一件作品时，打开的是那一件的存档。

## 限制
