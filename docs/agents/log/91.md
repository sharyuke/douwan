# 2026-11-06 下午 套索可以框选局部并单独拖动

用户要求：套索既能全选，也能手动框选某一部分，框住的局部可以单独拖动。

## 改法

- 点一下仍选中整张图案。拖出矩形只选框里的豆子，再拖只移动这一块。框外的豆子留在原地。
- 从选区里的豆子往外拉，会重新框选。按 Esc 取消选区。一次拖动仍是一步撤销，选框跟着回去。

## 验证

无头浏览器在 5180 预览上走了一遍：单击全选、Esc 取消、拖出局部框、拖动这块选区、撤销后豆子和选框都回到原位。
