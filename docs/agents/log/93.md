# 2026-11-06 傍晚 套索局部改成手绘轨迹，点住豆子直接拖整张

用户要求：选局部不要矩形框，手绘轨迹是什么形状，选区就跟着是什么形状；选整张时点住豆子直接拖。改完提交并发布。

## 改法

- 从空格按下并画出一圈，松手后轨迹收口，只选圈里的豆子。轮廓沿画出的轨迹，不再是外接矩形。
- 点住豆子按住就拖整张图案，不用先点一下再拖第二次。整张没有轮廓。
- 点在已有局部选区里的豆子上，只拖这一块。圈外的豆子留在原地。一次拖动仍是一步撤销，轮廓跟着回去。
- 拖出画布的豆子先停在画布外，拖回来按原来的相对位置落回去。

## 验证

5180 预览上用无头浏览器走了两步：从空格画出一圈不规则轨迹，轮廓不是矩形，拖圈里的豆子时轮廓跟着平移、圈外颜色不动，撤销后轮廓回到原位；点住豆子拖整张，红色色块整体右移，没有出现选区轮廓。
