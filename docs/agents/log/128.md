# 2026-11-11 晚上 接回微信扫码和手机验证码登录

11 月 10 日傍晚把后端从 11 月 1 日的二进制换成当前 main 时，微信扫码和手机验证码的路由没在这份源码里，线上 `/api/v1/auth/oauth/wechat/*` 与 `/api/v1/auth/sms/*` 都变成 404「接口不存在」。登录弹窗因此收起手机号页签，点微信登录也出不了二维码。

## 改法

从本机旧副本 `douwan-api/.tmp/wt-dev` 把微信 / QQ OAuth 与阿里云短信登录接回当前后端：路由、配置（沿用 qq 上已有的 `DOUWAN_OAUTH_WECHAT_*`、`DOUWAN_SMS_*`、`QQ_APP_*`）、`user_identities` / `sms_codes` 两张表。前端弹窗本来就会在短信 `configured` 时显示「手机号登录」，这次没有改前端。

## 验证

- 本机 `go test`：`internal/auth`、`internal/config` 通过。`internal/handler` 被本机 WDAC 拦住，没跑成。
- 公网：`/healthz` ok，`/readyz` database up。短信状态 `configured:true`。微信状态 `configured:true, available:true`。`/auth/oauth/wechat/start` 返回 `open.weixin.qq.com/connect/qrconnect`。邮箱登录接口仍在（错误密码返回 20004）。
- 真 Chrome 打开线上首页，桌面 1440×900 与手机 390×844：登录弹窗有「手机号登录」页签且手机号输入框可见，微信按钮可点，不再出现「或使用邮箱」。
