# 2026-11-06 凌晨 手机三点菜单把保存作品换成个人中心

用户要求只改手机端：导出旁边三个点点开的菜单，把「保存作品」换成「个人中心」。

## 改法

- `EditorView.vue`：手机工作台顶栏「⋯」菜单第一项从「保存作品」改成「个人中心」，点进去进 `/account`。颜色用量、返回首页不动。
- 保存仍走顶栏「保存」。菜单项不再依赖是否已有图纸。
- `scripts/verify-direct-entry.cjs`：断言菜单没有「保存作品」、有「个人中心」，并点进去落到 `/account`。补上本机 Chrome 路径。
- `scripts/audit-new-save.js`：③-3 改为点顶栏「保存」，不再走菜单。
