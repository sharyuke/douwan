# 2026-11-06 凌晨 手机端换色与填充对调，去掉画布上方图片名

用户要求把底部的填充和「更多工具」里的换色对调，并去掉画布上方的图片名称。

## 改法

- `EditorView.vue`：手机底部工具轨第三格从「填充」改成「换色」。点一格仍是整张图同色替换。
- 「更多工具」图纸处理第一项从「换色」改成「填充」。选中后抽屉收起，再打开时填充按钮保持高亮。
- 去掉图纸转换画布上方居中的作品名（`.msEditName`）。顶栏保存入口保留。
- `scripts/audit-mobile.js`：底部工具顺序断言改为「画笔,橡皮,换色,颜色,更多工具」。

## 验证

- 无头 Chrome 390×844：生成素材图后，画布上方没有作品名；底部是画笔 / 橡皮 / 换色 / 颜色 / 更多工具。
- 点「更多工具」看到填充；点填充后工具切到 `fill` 且抽屉收起；再打开时填充高亮。点底部换色后工具切到 `swap`。

## 提交与发布

- 只发前端。后端未动。
- 发布方式：本机 `pnpm build` → `tar` 打包 `dist` → `scp` 到 qq → 覆盖 `/var/www/dw.sharyuke.com`。静态前端不需要 reload nginx。
