# 2026-11-05 深夜 手机端图纸调整补上钉板与品牌色系

用户要求「手机端要把钉板选择和品牌色系选择加进图纸调整里」。桌面命令行本来就有这两项
（63 篇里图纸调整还专门去掉过尺寸与品牌色板），所以本次只改手机抽屉。

## 改法

- `ImageAdjustPanel.vue` 增加 `mobile` 开关，只在手机抽屉里渲染「图纸设置」段：
  钉板 `52 / 78 / 104 / 120 / 自定义`，品牌色系下拉（`PALETTE_BRANDS` 16 套）。
- 钉板改的是画布上限（`setCanvasCapacity`），成品尺寸仍由上面的 `SizeQuickCard` 调；
  面板里写明「钉板是画布上限，成品尺寸在上面调」。
- 超过免费版单边上限的钉板标灰，点击走 `need-pro` 提示。
- 品牌下拉调 `setBrand`，与颜色抽屉里的品牌色板同一套逻辑（换品牌会重匹配颜色与色号）。
- `EditorView.vue` 手机抽屉传 `mobile`。
- `scripts/audit-mobile.js` 增加图纸调整抽屉断言：5 个钉板按钮、首项 52、16 个品牌选项、
  抠图段仍在、关闭正常。
