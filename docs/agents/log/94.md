# 2026-11-06 傍晚 画笔按住 Shift 拖左键画直线

用户要求：画笔用 Shift + 左键画直线，并把这条操作写进快捷指引。

## 改法

- 画笔按住 Shift 再拖左键，从按下的格子连到指针所在的格子，中间走一条直线。鼠标拐弯也不会把弯路画进去。
- 不按 Shift 时仍是逐格涂抹。这一笔仍是一步撤销。
- 工具悬停说明、画布底部提示、帮助页快捷键表都写了「按住 Shift 拖左键画直线」。

## 验证

5180 预览上用无头浏览器走了一遍：鼠标走出折线，画面上是对角线，折角没有被涂到，撤销一次整条线退回。工具说明和画布底部都能看到这条指引。
