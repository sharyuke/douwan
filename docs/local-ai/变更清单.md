## 2. 实测数据汇总（真机 RTX 2060 6GB）

| 项目 | 结果 |
| --- | --- |
| 抠图（CPU / u2net） | 512×512 **0.2s**、640×800 **0.6s**；RGBA 输出，透明占比 49%–80% |
| 文生图 | 512×512 **6.0s**、640×640 **8.1s** |
| 卡通化 img2img | 512×512 **6.0s**、640×800 **23.3s**（含首次加载） |
| 显存 | ComfyUI 常驻 **2.2–2.3GB**；跑完一张后空闲 ~2.9GB |
| 隧道往返 | 探活 70–170ms；**完整抠图 0.38–0.46s** |
| 脚本 | 12 个 PowerShell 脚本语法全通过；8 项环境体检无阻塞项 |

**一项需要产品决策的负面结论**：在只有 SD 1.5 官方权重（唯一许可明确的底模）的前提下，
卡通化的「保形」与「风格化」不可兼得 —— denoise ≤0.65 保形但风格弱，≥0.75 风格像动漫
但**主体会被改写**。建议默认走前端确定性滤镜，模型卡通化作为可选「更艺术化」，
或先解决卡通 LoRA / ControlNet 的许可问题。详见 [test/阶段B-测试报告.md](test/阶段B-测试报告.md) §4.1。
