# 图纸交付与高清导出（需求 V1.1 第二部分）

本文记录「从图纸到完成 / 更多导出」合并成「图纸交付」后的入口迁移、导出能力、分板规则和验证结果。

## 1. 入口迁移表

旧入口已全部收进「图纸交付」，没有删除能力。画布工具栏右侧只保留一个主按钮「⬇ 高清导出」。

| 原入口 | 原功能 | 新位置 | 是否保留 |
| --- | --- | --- | --- |
| 画布下方「更多…」 | 打开导出与打印弹窗 | 图纸交付 › 整张图纸 | 保留 |
| 快速导出「图纸」 | 图纸 PNG | 整张图纸 › 图纸 PNG（高清） | 保留，改为按 DPI 重绘 |
| 快速导出「分板 PDF」 | 分板 PDF / 打印 | 整张图纸 › 分板 PDF / 打印；分板交付 › 分板 PDF | 保留 |
| 导出设置 | 网格 / 行列坐标 / 每格色号 / 图例 / 统计 / 背景 / PDF 方向 | 图纸交付 › 整张图纸 › 标注与背景 | 保留 |

新增能力：

- 分板交付：分板 PDF（每板一页）、分板 PNG ZIP、分板 JPG ZIP。
- 分板规格可切换：跟随图纸 / 29 格老规格 / 52 / 78 / 104 / 120 钉板 / 自定义单板格数。
- 分板预览：缩略图上直接画板边界与板号，并显示分板块数、行列数与每块覆盖格数。
- 导出前检查：图纸、色号映射、分板配置、可读性、预计尺寸/页数；只有致命问题阻止导出。
- 导出状态：准备中 / 生成中 / 成功 / 失败，失败可重试。

## 2. 导出格式与清晰度

| 格式 | 实现 | 说明 |
| --- | --- | --- |
| PNG | Canvas 按目标像素重绘 | 默认 300 DPI；可选 150 / 600 DPI；可透明背景 |
| JPG | Canvas 重绘后编码 JPEG | 透明区域铺白或用户选择的实色，不会出现黑底 |
| PDF | 浏览器打印生成 | 文字、表格、色号是矢量；每块板的网格是所选 DPI 的位图 |
| 材料 CSV | UTF-8 CSV | 品牌/系列、色号、颜色、数量、已有、缺少 |
| 复制清单 | 纯文本 | 品牌/系列 · 色号 · 数量 |
| SVG | 矢量 | 超过体积上限时先丢色号，再拒绝并说明 |
| ZIP | 无依赖 store 模式 | 分板图片按「图纸名_第01板_300dpi.png」命名 |

DPI 不是只写元数据：`dpiExportPlan()` 用「豆径 mm ÷ 25.4 × DPI」算每格像素，再乘格数得到真实输出尺寸；超过浏览器单张画布上限时逐格降档，并在界面和状态栏写明实际 DPI、像素尺寸和页数。

## 3. 分板规则

- 默认沿用图纸自己的 `boardSize`；用户可在「分板交付」里临时换规格，不写回图纸。
- 单板见方（行列相同），与现有 52 / 78 / 104 / 120 钉画线板数据一致；29 格仅用于老规格。
- 分板从左上角开始按行优先编号，边界由 `boardLayout()` 统一计算，保证不重叠、不漏格。
- 每板统计用 `boardMaterials()` 从同一份网格数据计算；全图汇总用 `materialList()`。
- PDF 每板一页，带板号、全图覆盖范围、本板材料图例；最后附材料总表。
- 单板图（界面预览 / PDF 板图 / ZIP 图片）的列 / 行坐标一律沿用整张图纸的全局编号，
  不从 1 或 0 重新起算 —— 这样单板图和整图对得上，拼到第几列就是第几列。
- 「分板交付」左栏把预览拆成每块板一张卡：卡头是板号、全图列 / 行范围、本板颗数与色数，
  卡底是这块板的色号图例（色号 × 数量）。
- 分板图片带页眉：板号、全图列/行范围、本板颗数与色数；文件名固定为「图纸名_第NN板_<dpi>dpi」。

## 4. 技术实现

- 图像、色号、坐标、统计共用 `pattern.cells` / `pattern.palette`，不从界面文本反推。
- 导出画布使用 `createExportCanvas()` 的 `__dpr` 旁路，输出像素由导出配置决定，不受屏幕 `devicePixelRatio` 影响。
- 整图与分板都先算计划再绘制；大图按单张 4096 px、1600 万像素、分板 PDF 总解码约 40M 像素三道闸门降档。
- 编辑器 UI、工具栏、选区控制点不会进入导出画布。
- 每次导出直接读取当前 `pattern`，画布修改后再次导出会同步更新。

| 检查 | 结果 |
| --- | --- |
| 全站 84 页 × 4 视口 | 0 console 错误、0 横向溢出、0 空白画布 |

| 600 DPI 大图降档 | 450×450 格整图降到 3628×3628 px，并标记 capped |
| 分板规格切换 | 52×52 图纸按 29 格切 → 4 块；自定义 29 格同样 4 块；切回跟随图纸 → 1 块 |
| 分板 ZIP | 文件头 `PK\x03\x04`、中央目录 `PK\x05\x06`，可正常解压 |
| PDF 标注 | 含全局「全图」列 / 行坐标与 DPI；单板坐标不从 1 重新起算 |
| 分板预览 | 每块板一张卡，卡头带板号 / 全局列行 / 颗数，卡底带色号 × 数量图例 |
| CSV | 表头含「品牌/系列」，行内含真实品牌与色号 |
| 移动端入口 | 高清导出按钮在画布下方操作区，手机可见 |

## 6. 已知限制

- PDF 的板图是位图，按所选 DPI 重绘；文字、表格、色号是矢量。浏览器打印是当前技术栈下风险最低的 PDF 方案。
- 600 DPI 对大画布会自动降档，界面会写明实际 DPI；这是为了避免浏览器崩溃或静默降质。
- 分板图片组（ZIP）不附带整图材料总表；需要汇总时用分板 PDF 或材料 CSV。
- 账号删除 / 数据导出仍未实现，见账号文档的待办。
